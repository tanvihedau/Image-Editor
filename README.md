# 🖼️ Browser-Based Image Editor

A simple browser-based image editor built with **HTML, CSS, and JavaScript** to practice DOM manipulation, image processing, and CSS filters.

## ✨ Features

- Upload and edit images in the browser  
- Adjust filters using sliders:
  - Brightness
  - Contrast
  - Saturation
  - Hue Rotation
  - Blur
  - Grayscale
  - Sepia
  - Opacity
  - Invert

## 🎨 Presets
- Normal  
- Drama  
- Vintage  
- Cinematic  
- Cool Blue  
- Warm Sunset  
- Noir  

## ⚙️ Functionalities
- Reset edits  
- Download edited image  

## 🛠 Tech Stack
- HTML5  
- CSS3  
- Vanilla JavaScript  

## 📚 Concepts Practiced
- DOM Manipulation  
- Event Handling  
- CSS Filters  
- JavaScript Objects  
- Canvas API
